## 무엇이 달라졌나

`measure.py`로 잰 값이다. 본문 산문만 세고 제목과 표는 뺐다.

| 신호 | 전 | 후 |
|---|---|---|
| T1 줄표 | 4개, 227자당 1개 (교정 필요) | 0개 |
| T2 명사형 종결 | 17개 | 2개 |
| T4 메타 예고문 | 4개 | 0개 |
| T7 번역투 | 2개 | 0개 |
| T7 논문체 | 1개 | 0개 |
| 광고체 | 1개 | 0개 |
| 접속부사 | 3개 | 0개 |

스킬이 매긴 총점은 110점 만점에 78점, 0.71이었다. 교정을 강권하는 구간이다.

**수치와 표와 문단 순서는 그대로다.** 69.2B 달러, 14.2퍼센트, 87퍼센트, 성장률 표,
소제목 체계가 전부 원문 그대로 남았다. 바뀐 것은 문장의 결뿐이다.

## 대표 대조

전체 열두 건 중 여섯을 뽑았다. 나머지는 [diagnosis.md](diagnosis.md)에 있다.

**제목** (T1 줄표 동격, T3 상투 비유)

> 전: 데이터 품질의 새로운 지평 — 다시 쓰이는 표준의 좌표
> 후: 2026년 데이터 품질 관리 시장의 구조적 전환

앞은 줄표 뒤에 앞말을 다시 풀고 "지평"과 "좌표"를 겹쳐 쓴다. 무슨 글인지는 안 보인다.
뒤는 무엇에 관한 글인지 그대로 말한다.

**메타 예고문** (T4)

> 전: 한 줄로 옮긴다 — 데이터는 더 이상 자산이 아니라 부채가 되어가고 있다는 점이다.
> 후: 데이터는 더 이상 자산이 아니라 부채가 되어가고 있다.

무엇을 할지 예고하는 말을 지우면 문장이 바로 선다.

**논문체** (T7)

> 전: 본 보고서는 2026년 데이터 품질 관리 시장의 구조적 전환을 규명하고자 한다.
> 후: 이 글은 2026년 데이터 품질 관리 시장에서 일어나는 구조적 전환을 다룬다.

**수치 과적재** (T8)

> 전: 시장 규모는 69.2B 달러이고, 연평균 성장률은 14.2%이며, 도입률은 4개 주요 영역에서 87%에 달한다는 점이다.
> 후: 시장 규모는 69.2B 달러다. 연평균 성장률은 14.2%, 품질 관리 도입률은 4개 주요 영역에서 87%에 이른다.

한 문장에 몰아넣은 지표를 끊었다. 수치는 하나도 안 바뀌었다.

**세 마디 강박** (T9, T2)

> 전: 이러한 맥락에서 볼 때, 기업의 대응은 세 가지 방향으로 정리된다. 첫째는 측정 체계의 수립이고, 둘째는 거버넌스의 정비이며, 셋째는 자동화의 도입이다.
> 후: 기업의 대응은 세 방향으로 모인다. 측정 체계를 세우고, 거버넌스를 정비하고, 자동화를 들인다.

명사로 된 항목을 동사로 풀었다. 셋이라는 사실은 남았다.

**자사 점프** (T11)

> 전: 그리고 바로 이 지점에서 우리 회사의 솔루션은 혁신적인 접근을 제시한다. 우리는 이 공백을 정조준한다 — 진단부터 처방까지 끊기지 않는 하나의 파이프라인. 이번 보고서는 우리를 데이터 품질 카테고리의 리더로 격상하는 좌표가 될 것이다.
> 후: 우리 회사는 이 지점에 주목한다. 진단부터 처방까지 끊기지 않는 파이프라인으로 이 공백에 대응하고자 한다. 이번 보고서가 데이터 품질 카테고리에서 우리의 입지를 다지는 계기가 되길 기대한다.

"정조준한다", "격상한다" 같은 단정형 홍보 어휘가 빠졌다. 자사를 분석의 결론이 아니라
반응으로 옮긴 것이다.

## 스킬이 하지 않은 것

두 가지를 그대로 뒀고, 둘 다 근거가 있다.

**볼드 한 줄 요약을 다 지우지 않았다.** 원문에는 두 개가 있었는데 하나만 본문에 녹이고
하나("규제는 품질을 요건으로 만들었다")는 남겼다. T6의 교정 방향은 요약을 없애라가 아니라
**같은 형식의 반복을 깨라**이다. 규칙대로 움직인 것이다.

**자사 문단을 편집자 노트로 떼어 내지는 않았다.** 그것이 T11의 정석이지만 문단 순서를
바꾸지 말라는 지시가 있었다. 같은 자리에서 어조만 낮췄고, 그 판단을 진단에 적어 두었다.

## 다시 해 보려면

```bash
claude plugin marketplace add pebblous/korean-tech-writing
claude plugin install korean-tech-writing@korean-tech-writing
```

그다음 아무 편집기 세션에서 이렇게 말하면 된다.

```
before.md 를 진단하고 교정해 줘
```

수치만 먼저 보고 싶으면 측정기를 직접 돌려도 된다.

```bash
python3 ~/.claude/plugins/*/korean-tech-writing/*/skills/ko-prose-humanizer/measure.py before.md
```

## 한 가지 알아 둘 것

여기 실린 진단은 `measure.py`를 못 돌린 상태에서 나왔다. 실행 승인이 막혀 스킬이 열한 종
기준을 직접 대조하는 쪽으로 넘어갔다고 진단 첫 줄에 적혀 있다. 결과는 제대로 나왔지만,
측정기를 쓰면 숫자가 더 정확하다. 승인을 물으면 허용하는 편이 낫다.
