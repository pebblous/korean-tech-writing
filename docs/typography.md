# 한국어 긴 글의 조판

내용이 좋아도 조판이 나쁘면 읽히지 않는다. 특히 한국어는 영어와 조건이 달라서, 영어권 기본값을
그대로 쓰면 빽빽해 보인다.

이 문서는 화면에서 읽히는 긴 글을 전제한다. 인쇄물은 조건이 다르다.

---

## 1. 한국어가 영어와 다른 점

세 가지다.

1. **글자당 정보 밀도가 높다.** 같은 뜻을 더 적은 글자로 담으므로 한 줄이 시각적으로 더 무겁다.
   같은 줄간격이면 한국어 쪽이 더 답답해 보인다.
2. **글자에 위아래 여백이 적다.** 라틴 문자는 올라가는 획과 내려가는 획이 만드는 여백이 있는데
   한글은 대체로 네모틀 안에 꽉 찬다. 그만큼 줄간격으로 벌려 주어야 한다.
3. **기울임꼴이 없다.** 아래 4절에서 따로 다룬다.

결론은 하나다. **한국어 긴 글은 영어보다 줄간격을 넓게 잡는다.**

---

## 2. 권장 값

| 항목 | 값 | 이유 |
|---|---|---|
| 본문 글자 크기 | 18픽셀 | 16픽셀은 긴 글에 작다 |
| 본문 줄간격 | 2.0 이상 (2.1 권장) | 1.5는 한국어 긴 글에 부적합하다 |
| 자간 | -0.01em | 한글은 미세하게 좁혀야 덩어리로 읽힌다 |
| 목록 항목 글자 크기 | 본문과 같게 | 본문의 95퍼센트 이하로 줄이지 않는다 |
| 목록 항목 줄간격 | 2.0 | 본문에 준한다 |
| 카드·상자 안의 글자 | 본문과 같게 | 요소마다 다르면 시선이 흔들린다 |
| 문단 아래 여백 | 1.25rem 안팎 | 문단의 경계가 보여야 한다 |

### 자주 나오는 잘못

```
글자가 너무 작다
  카드 설명 0.875rem (14픽셀)
  예시 문구 0.8rem (12.8픽셀)

줄간격이 너무 좁다
  본문 1.5
  목록 1.5

요소마다 크기가 다르다
  카드 가 0.9rem
  카드 나 0.85rem
```

**가장 흔한 실수는 카드나 상자 안의 글자를 본문보다 작게 만드는 것**이다.
카드 안에 든 글도 읽으라고 넣은 글이다. 본문과 같은 크기로 둔다.

---

## 3. 제목 계층

| 층 | 굵기 | 줄간격 | 비고 |
|---|---|---|---|
| 글 제목 | 800 | 1.3 | 절 제목보다 확실히 크게 |
| 절 제목 | 700 | 기본 | |
| 소절 제목 | 600 | 기본 | |
| 카드 제목 | 600 | 기본 | |

글 제목의 줄간격만 본문보다 좁다(1.3). 큰 글씨는 줄간격이 넓으면 흩어져 보인다.

화면 폭이 좁을 때와 넓을 때의 크기를 다르게 잡는다. 좁은 화면 36픽셀, 넓은 화면 48픽셀 정도가
무난하다.

---

## 4. 한국어에 기울임꼴을 쓰지 않는다

**한글 글꼴에는 기울임꼴 디자인이 없다.** 기울여 보이는 것은 프로그램이 네모난 글자를 기계적으로
비스듬히 밀어 낸 결과이고, 그래서 획의 굵기가 어긋나고 읽기 어려워진다.

인용문, 강조, 용어 표시 어디에도 쓰지 않는다.

강조가 필요하면 다른 방법을 쓴다.

- 굵기를 600이나 700으로 올린다
- 배경색이나 왼쪽 테두리로 구분한다
- 강조 색을 준다

영어 낱말이 섞여 있어도 마찬가지다. 한 문장 안에서 영어만 기울이면 줄이 들쭉날쭉해진다.

---

## 5. 줄 길이

한 줄이 너무 길면 다음 줄의 시작을 찾기 어렵고, 너무 짧으면 눈이 자주 되돌아간다.
한국어 본문은 **한 줄에 40자 안팎**이 편하다. 본문 영역의 폭을 그에 맞춰 제한한다.

화면이 넓다고 본문을 화면 전체로 늘이지 않는다.

---

## 6. 점검표

- [ ] 본문 글자가 18픽셀인가
- [ ] 본문 줄간격이 2.0 이상인가
- [ ] 목록 항목의 글자 크기가 본문과 같은가
- [ ] 카드와 상자 안의 글자가 본문과 같은 크기·줄간격인가
- [ ] 한국어에 기울임꼴을 쓴 곳이 없는가
- [ ] 본문 한 줄이 40자 안팎인가
- [ ] 문단 사이 여백으로 경계가 보이는가
